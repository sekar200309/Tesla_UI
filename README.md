# Tesla Landing Page Clone

A responsive clone of the official Tesla landing page, built using **HTML**, **CSS**, and **JavaScript**.

## 🚗 Live Demo

Check it out here: [https://teslaui09.vercel.app/](https://teslaui09.vercel.app/)

## 📂 Repository

[GitHub Repository](https://github.com/sekar200309/Tesla_UI.git)

## ✨ Features

- **Responsive Design:** Optimized for all device sizes.
- **Smooth Scrolling:** Seamless navigation experience between sections.
- **Interactive Navigation Menu:** Modern, dynamic navbar for easy access.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sekar200309/Tesla_UI.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Tesla_UI
   ```
3. **Open `index.html` in your browser.**

No build tools or dependencies required.
